## Featured projects

### [Nova](https://github.com/Lakshana-2007/nova)
An agentic personal assistant organized around a root agent and multiple focused skills. The repository explores tool integration, memory, semantic search, scheduled tasks, and a React/FastAPI application architecture.

### [Betty's Bird Brain](https://github.com/Lakshana-2007/ai-customer-service-agent)
A multi-tool customer-service agent for a fictional bird-specialty shop. It combines Google ADK, MCP Toolbox, a Next.js interface, streamed responses, SQL-backed product data, and grounded search integrations.

### [FreshGuard](https://github.com/Lakshana-2007/FreshGuard)
A full-stack food freshness monitoring project with a React frontend, FastAPI backend, PostgreSQL, authentication, computer-vision classification, and shelf-life forecasting. Model performance and deployment claims should be interpreted within the project's documented limitations.

### [Breast Cancer Analysis](https://github.com/Lakshana-2007/breast_cancer_analysis)
A reproducible educational case study using the Wisconsin Diagnostic Breast Cancer dataset. It includes exploratory analysis, visualizations, preprocessing, an MLP classifier, and generated evaluation artifacts. It is not a medical diagnostic system.

### [Notification Rule Builder](https://github.com/Lakshana-2007/notification-builder)
A full-stack rule-building application with a React frontend, Express backend, MySQL databases, schema discovery, rule evaluation, and event logs.
